SHIV GANGA MOBILE - NETLIFY DEPLOY

1. netlify.com पर Login करें।
2. GitHub पर नई repository बनाकर इस ZIP की extracted files upload करें।
3. Netlify में Add new project > Import from Git चुनें।
4. अपनी GitHub repository connect करें।
5. Build command: npm run build
6. Publish directory को automatic/खाली रहने दें और Deploy दबाएँ।
7. Temporary Admin PIN: 2580

IMPORTANT:
- यह server वाला Next.js app है, इसलिए सामान्य drag-and-drop static upload नहीं करना है।
- GitHub से Netlify connect करने पर One-Time Spin और database storage सही काम करेंगे।
